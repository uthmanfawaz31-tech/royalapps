## 🚀 Quick Setup & Free Hosting Deployment

1. Upload all files to your web hosting root (`htdocs` or `public_html`).
2. Open `http://your-domain.com/install.php` in your browser.
3. The 2-minute installer configures the SQLite database and seeds the Royal Media apps automatically.
4. Access your Admin Control Panel at `http://your-domain.com/admin/login.php` (Default: `admin` / `admin123`).
